# 住宅購入の資金計画シミュレーター

住宅の購入を検討している人や不動産会社の担当者が、**物件価格と借入条件を入れるだけで、諸費用の内訳・毎月の返済額・返済負担率を一枚の資金計画書にまとめられる**ブラウザツールです。

**▶ デモ：** https://aksn7104.github.io/housing-fund-simulator/

## できること

- 諸費用を項目ごとに自動計算（仲介手数料、印紙税、登録免許税、融資手数料など）
- 元利均等・元金均等の毎月返済額、総返済額、利息総額
- 年収に対する返済負担率と、銀行の審査用金利で計算した負担率を判定
- 年ごとの返済額と残高の一覧
- 資金計画書をそのまま印刷（PDF保存）
- 入力条件をURLにしてコピー（お客様や家族との共有に）

## 計算の前提

| 項目 | 計算方法 |
|---|---|
| 仲介手数料 | 宅建業法の上限額（400万円超：価格×3%＋6万円）＋消費税 |
| 印紙税（売買契約書） | 軽減税率（2027年3月31日までに作成された契約書） |
| 印紙税（ローン契約書） | 金銭消費貸借契約書の税額 |
| 登録免許税 | 土地の所有権移転1.5%、建物は新築の保存0.15%／中古の移転0.3%（住宅用家屋の軽減）、抵当権設定0.1%。評価額が未入力のときは価格の約6割と仮定 |
| 融資手数料 | 借入額×料率（初期値2.2%） |
| 返済負担率 | 1年目の年間返済額 ÷ 税込年収 |

軽減税率の適用期限や要件は税制改正で変わるため、利用前に最新の情報を確認してください。この計算は概算であり、実際の金額は物件・金融機関・契約時期によって異なります。

## 使い方

`index.html` をブラウザで開くだけで動きます。サーバーやインストールは不要で、入力内容はどこにも送信・保存されません。

## 技術

- HTML / CSS / JavaScript（ライブラリ不使用、1ファイル構成）

## カスタマイズのご相談

会社ロゴ・配色の変更、自社の諸費用の基準に合わせた調整、ホームページへの埋め込みなどを承ります。
