# 住宅購入の資金計画シミュレーター

住宅の購入を検討している人や不動産会社の担当者が、**物件価格と借入条件を入れるだけで、諸費用の内訳・毎月の返済額・返済負担率を一枚の資金計画書にまとめられる**ブラウザツールです。

**▶ デモ：** https://aksn7104.github.io/housing-fund-simulator/

> **ご利用の前にお読みください**
> - この計算は**概算**です。実際の金額は、物件・金融機関・契約時期によって異なります。
> - 「購入時に必要なお金」と「ローンの返済」を計算します。**購入後にかかる税金や毎月の費用（固定資産税、管理費、修繕積立金など）は含んでいません。**
> - 税制・法令は改正されることがあります。ご利用時点の最新情報は、公式の情報や専門家でご確認ください。
> - 詳しくは、下の「まだ計算に含めていないこと」「法制度・税制の変更について」をご覧ください。

## できること

- 諸費用を項目ごとに自動計算（仲介手数料、印紙税、登録免許税、融資手数料など）
- 元利均等・元金均等の毎月返済額、総返済額、利息総額
- 年収に対する返済負担率と、銀行の審査用金利で計算した負担率を判定
- 年ごとの返済額と残高の一覧
- 資金計画書をそのまま印刷（PDF保存）
- 入力条件をURLにしてコピー（お客様や家族との共有に）

## 使い方

1. **条件を入れる**：画面左の入力欄に、物件・借入・収入の条件を入れます。初めから例の数字が入っているので、書き換えるだけで使えます。
2. **結果を見る**：入力するたびに、画面右の「資金計画書」が自動で変わります。「計算する」ボタンはありません。
3. **印刷・共有する**：「資金計画書を印刷する」で印刷（PDF保存）、「この条件のリンクをコピー」で同じ条件の画面を共有できます。

### 入力項目と計算の関係

#### 物件

| 入力欄 | 何を入れるか | 計算への影響 |
|---|---|---|
| 物件の種類 | 新築／中古のマンション・一戸建てから選択 | 登録免許税の建物の税率、土地と建物の評価額の割り振り、火災・地震保険の目安、修繕積立基金の有無が変わります。仲介手数料のチェックも、新築はオフ、中古はオンに切り替わります |
| 物件価格 | 万円単位 | 仲介手数料、印紙税、登録免許税（評価額を入れない場合）の計算のもとになります。税込の価格を入れてください |
| 仲介で購入する | 不動産会社の仲介かどうか | チェックすると仲介手数料が入ります。売主から直接買う新築は、通常かかりません |

#### 借入

| 入力欄 | 何を入れるか | 計算への影響 |
|---|---|---|
| 頭金 | 万円単位 | 借入額は「物件価格 − 頭金」になります |
| 諸費用もローンに含める | チェックで有効 | 借入額が「物件価格 − 頭金 ＋ 諸費用」になります。借入額が増えると、印紙税・登録免許税・融資手数料も増えるため、自動で再計算します |
| 金利（年） | 年率（%） | 毎月の返済額と利息の計算に使います。全期間で一定の金利として計算します |
| 返済期間 | 年（1〜50年） | 毎月の返済額と利息の計算に使います |
| 借入時の年齢 | 任意 | 入れると、完済時の年齢を表示します。80歳以上になると注意を表示します |
| 返済方法 | 元利均等／元金均等 | 元利均等は毎月同じ額、元金均等は毎月少しずつ減ります。元金均等の画面には初回の額を表示します |

#### 収入

| 入力欄 | 何を入れるか | 計算への影響 |
|---|---|---|
| 年収（税込） | 万円単位。夫婦合算の場合は合計額 | 返済負担率 ＝ 1年目の年間返済額 ÷ 年収 |
| 月の手取り | 任意 | 入れると「初回の毎月の返済額 ÷ 月の手取り」を表示します |
| 審査用の金利 | 銀行が審査で使う想定金利（初期値3.5%） | この金利で元利均等として計算した負担率を、判定に使います |

#### 諸費用の前提（「諸費用の前提を変更する」を開くと表示）

| 入力欄 | 何を入れるか | 計算への影響 |
|---|---|---|
| 融資手数料 | 借入額に対する料率（初期値2.2%） | 借入額 × 料率。保証料型の場合は0にして、金額を「その他」に入れます |
| 土地・建物の固定資産税評価額 | 分かる場合のみ。空欄で構いません | 空欄の場合は、評価額を物件価格の約6割と仮定し、土地と建物に割り振って登録免許税を計算します（マンションは土地3割、一戸建ては土地5割） |
| 司法書士報酬 | 初期値10万円 | そのまま諸費用に足します |
| 火災・地震保険 | 空欄で自動 | 空欄の場合は、5年分の目安として、マンション8万円、一戸建て25万円で計算します |
| 不動産取得税 | 初期値0円 | **自動計算はしません。**分かる場合は金額を入れてください |
| 修繕積立基金 | 初期値40万円（新築マンションのみ） | 新築マンション以外では入力できません |
| その他 | 初期値10万円 | 固定資産税の精算金、引っ越し費用など、上記にない費用を入れてください |

### 結果の見方

- **毎月の返済額**：画面中央の大きな数字です。元金均等の場合は初回の額です。
- **返済負担率**：1年目の年間返済額 ÷ 年収です。
- **審査金利での負担率**：審査用の金利で計算した負担率です。実際の金利が低くても、金融機関の審査では、この考え方で見られることが多いとされています。
- **判子（判定）**：次の基準で表示します。年収が未入力、または借入が0円の場合は判定しません。

| 判定 | 基準 |
|---|---|
| ゆとり | 返済負担率25%以下、かつ審査金利での負担率35%以下 |
| 要検討 | 返済負担率35%以下、かつ審査金利での負担率40%以下（ゆとりに当てはまらない場合） |
| 超過 | 上記のどちらにも当てはまらない場合 |

この基準は、このツール独自の目安です。金融機関ごとの審査基準とは異なります。

- **購入にかかるお金／用意するお金**：物件価格と諸費用の合計と、その調達方法（ローンと自己資金）です。
- **諸費用の内訳**：項目ごとの金額と、計算の根拠を表示します。
- **返済の総額**：総返済額、うち利息、完済時の年齢です。
- **年ごとの返済額と残高**：「年ごとの返済額と残高を見る」を開くと表示します。

### 計算例（初期値のまま）

中古マンション・物件価格4,000万円・頭金400万円・金利0.8%・35年・元利均等・年収650万円の場合です。

- 借入額：3,600万円
- 毎月の返済額：98,302円
- 返済負担率：18.1%
- 審査金利（3.5%）での負担率：27.5%
- 判定：ゆとり

### 印刷と共有

- **印刷**：入力欄を除いた「資金計画書」の部分だけが印刷されます。印刷画面で保存先にPDFを選ぶと、PDFにできます。
- **共有リンク**：入力した条件が、URLの「#」より後ろに入ります。リンクを受け取った人は、同じ条件の画面を開けます。リンクを渡した相手には、入力した数字が見えます。

## 計算の前提

| 項目 | 計算方法 |
|---|---|
| 仲介手数料 | 宅建業法の上限額（400万円超：価格×3%＋6万円）＋消費税 |
| 印紙税（売買契約書） | 軽減税率（2027年3月31日までに作成された契約書） |
| 印紙税（ローン契約書） | 金銭消費貸借契約書の税額 |
| 登録免許税 | 土地の所有権移転1.5%、建物は新築の保存0.15%／中古の移転0.3%（住宅用家屋の軽減）、抵当権設定0.1%。評価額が未入力のときは価格の約6割と仮定 |
| 融資手数料 | 借入額×料率（初期値2.2%） |
| 返済負担率 | 1年目の年間返済額 ÷ 税込年収 |

## まだ計算に含めていないこと

現在のバージョン（v1）では、次のものは計算していません。実際の資金計画では、別途ご確認ください。

- 不動産取得税の自動計算（金額を自分で入力する欄はあります）
- 固定資産税・都市計画税（毎年かかる税金）
- 管理費、修繕積立金、駐車場代など、毎月かかる費用
- 住宅ローン控除
- 登録免許税の、住宅の性能による軽減（長期優良住宅など）の区別
- 団体信用生命保険料、保証料（保証料型の場合は「その他」に入力してください）
- 引っ越し、家具・家電、リフォームの費用
- ボーナス払い、繰り上げ返済
- 金利の変動（全期間で同じ金利として計算します）
- 低価格の物件に認められている仲介手数料の特例

## 法制度・税制の変更について

- 税率、軽減措置の適用期限、適用の要件は、税制改正で変わることがあります。
- 例として、印紙税の軽減は「2027年3月31日までに作成された契約書」を前提にしています。この日以降の契約書は、税額が変わる可能性があります。
- 登録免許税の軽減（住宅用家屋、土地）も、適用期限や要件が変わることがあります。
- 計算の前提は、2026年10月時点の情報をもとに作成しています。すべての項目について、最新の公式情報との照合が終わっているわけではありません。
- 実際の手続きや契約の前には、国税庁・法務局・自治体などの公式情報、または税理士・司法書士・金融機関などの専門家にご確認ください。

## 今後の更新予定

次のバージョン（v1.1）で、次の内容を予定しています。時期は未定で、内容が変わることもあります。

- 登録免許税を、住宅の性能区分に応じて計算する

- 管理費・修繕積立金・固定資産税を含めた「毎月の住居費」の表示と、家賃との比較
- 画面の装飾を、資料やレポートに近い見た目に整える
