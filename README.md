# 住宅購入の資金計画シミュレーター

住宅の購入を検討している人や不動産会社の担当者が、**物件価格と借入条件を入れるだけで、諸費用・税金・住宅ローン控除・維持費まで含めた「月々の住居費」と実質負担を、一枚の資金計画書にまとめられる**ブラウザツールです。

**▶ デモ：** https://aksn7104.github.io/housing-fund-simulator/

> **ご利用の前にお読みください**
> - この計算は**概算**です。実際の金額は、物件・金融機関・契約時期・お住まいの自治体によって異なります。
> - 固定資産税評価額を入れない場合は、物件価格から**仮定の評価額**を置いて、登録免許税・不動産取得税・固定資産税を計算します。分かる場合は入力してください。
> - 税制・法令は改正されることがあります。ご利用時点の最新情報は、公式の情報や専門家でご確認ください。
> - 詳しくは、下の「まだ計算に含めていないこと」「法制度・税制の変更について」をご覧ください。

## できること

- 諸費用を項目ごとに自動計算（仲介手数料、印紙税、登録免許税、融資手数料など）
- 住宅の性能（長期優良住宅・低炭素住宅・買取再販）、耐震基準、床面積に応じた登録免許税の判定
- 不動産取得税の概算（新築・中古の控除、住宅用土地の減額）
- 住宅ローン控除の試算（2026〜2030年入居、省エネ性能・子育て世帯の区分に対応）
- 管理費・修繕積立金・固定資産税を含めた**月々の住居費**と、完済までの**実質負担の総額**
- 元利均等・元金均等の毎月返済額、返済負担率と判定、年ごとの返済額・残高・控除額
- 資金計画書の印刷（PDF保存）、入力条件をURLにして共有

## 使い方

1. **条件を入れる**：画面左の入力欄に条件を入れます。初めから例の数字が入っているので、書き換えるだけで使えます。入力欄は「物件」「借入」「収入」「住宅ローン控除」「維持費」「諸費用・税金の前提」に分かれていて、見出しを押すと開閉できます。
2. **結果を見る**：入力するたびに、画面右の「資金計画書」が自動で変わります。スマートフォンでは、画面上部に月々の住居費が常に表示されます。
3. **印刷・共有する**：「資金計画書を印刷する」で印刷（PDF保存）、「この条件のリンクをコピー」で同じ条件の画面を共有できます。

### 入力項目と計算の関係

#### 1 物件

| 入力欄 | 何を入れるか | 計算への影響 |
|---|---|---|
| 物件の種類 | 新築／中古のマンション・一戸建て | 登録免許税（新築は保存、中古は移転とみなす）、不動産取得税の控除、住宅ローン控除の限度額、評価額の割り振りが変わります。仲介手数料のチェックも、新築はオフ、中古はオンに切り替わります |
| 物件価格（税込） | 万円単位 | 各種の計算のもとになります |
| うち建物の消費税 | 業者が売主のときの建物の消費税 | 仲介手数料と売買契約書の印紙税を、税抜価格で計算します |
| 床面積（登記簿） | ㎡。マンションは内法面積 | 登録免許税の軽減（50㎡以上）、不動産取得税の軽減（40〜240㎡）、住宅ローン控除（40㎡以上、条件により50㎡以上）の判定に使います |
| 住宅の省エネ・認定 | その他／省エネ基準適合／ZEH水準／長期優良／低炭素 | 住宅ローン控除の限度額が変わります。新築の長期優良・低炭素は、登録免許税と不動産取得税の軽減も変わります |
| 新築年月 | 中古のみ。空欄なら1997年4月以後として計算 | 1981年以前の場合は、耐震基準の証明がないと各種の軽減を受けられません。不動産取得税の控除額も新築年月で決まります |
| 耐震基準適合証明書などがある | 1981年以前の建築で、証明書がある場合 | 各種の軽減の対象になります |
| 買取再販住宅 | 宅建業者が一定の改修をして販売する中古 | 登録免許税（建物）が0.1%になり、住宅ローン控除は買取再販の限度額（長期優良・低炭素4,500万円など）で計算します |
| 仲介で購入する | 不動産会社の仲介かどうか | 仲介手数料が入ります |

#### 2 借入・3 収入

| 入力欄 | 計算への影響 |
|---|---|
| 頭金、諸費用もローンに含める | 借入額は「物件価格 − 頭金」（含める場合は ＋ 諸費用）。借入額が増えると印紙税・登録免許税・融資手数料も再計算します |
| 金利、返済期間、返済方法 | 毎月の返済額と利息。全期間で一定の金利として計算します |
| 借入時の年齢 | 完済時の年齢を表示します |
| 年収（税込） | 返済負担率 ＝ 1年目の年間返済額 ÷ 年収。住宅ローン控除の所得要件の判定にも使います（給与収入のみと仮定） |
| 月の手取り | 「毎月の返済額 ÷ 月の手取り」を表示します |
| 審査用の金利 | この金利で元利均等として計算した負担率を、判定に使います |

#### 4 住宅ローン控除

| 入力欄 | 計算への影響 |
|---|---|
| 入居予定年 | 2026〜2030年の入居が対象です。範囲外の場合は計算しません |
| 子育て世帯・若者夫婦世帯 | 限度額の上乗せの対象になります（床面積50㎡以上が必要） |
| 年間の所得税額・住民税（所得割） | 控除は実際に納めている税額が上限です。住民税からは課税総所得金額等の5%（最高9.75万円）までで、所得割の約半分として計算します。空欄の場合は「税額が十分ある場合の最大額」として表示します |

#### 5 維持費

| 入力欄 | 計算への影響 |
|---|---|
| 管理費・修繕積立金（マンション）／修繕の積立（一戸建て） | 月々の住居費と、返済期間中の維持費に入ります。将来の値上がりは見込んでいません |
| 固定資産税・都市計画税 | 年額を入れると、その金額を使います。空欄の場合は評価額から概算します |

#### 6 諸費用・税金の前提（わかれば入力）

| 入力欄 | 計算への影響 |
|---|---|
| 土地・建物の固定資産税評価額 | 空欄の場合は、物件価格の約6割と仮定し、土地と建物に割り振ります（マンションは土地3割、一戸建ては土地5割） |
| 敷地面積 | 不動産取得税の土地分（住宅用土地の減額）に使います。空欄の場合は、減額で土地分が0円になるとみなします |
| 融資手数料、司法書士報酬、火災・地震保険、修繕積立基金、その他 | そのまま諸費用に入ります。初期値は2026年10月時点の目安です |

### 結果の見方

- **月々の住居費（1年目・控除後）**：毎月の返済額 ＋ 管理費 ＋ 修繕積立金 ＋ 固定資産税等÷12 − 住宅ローン控除÷12 です。家賃と比べるときの目安になります。
- **実質負担の総額**：自己資金 ＋ 不動産取得税 ＋ ローンの総返済額 ＋ 返済期間中の維持費 − 住宅ローン控除の合計です。
- **判子（判定）**：次の基準で表示します。年収が未入力、または借入が0円の場合は判定しません。審査の目安は、年収400万円未満は30%、400万円以上は35%です（フラット35の基準）。

| 判定 | 基準 |
|---|---|
| ゆとり | 返済負担率25%以下、かつ審査金利での負担率が審査の目安以下 |
| 要検討 | ゆとり・超過のどちらにも当てはまらない場合 |
| 超過 | 返済負担率が審査の目安を超える、または審査金利での負担率が目安＋5%を超える場合 |

この判定は、このツール独自の目安です。金融機関ごとの審査基準とは異なります。

- **軽減が受けられない場合**：床面積や耐震基準の要件を満たさない場合は、その理由を赤字で表示し、本則の税率で計算します。
- **適用期限を過ぎた税率**：税率の適用期限を過ぎている場合は「適用期限を過ぎています」と表示します。

### 計算例（初期値のまま）

中古マンション・物件価格4,000万円・頭金400万円・金利0.8%・35年・元利均等・年収650万円・床面積70㎡・2026年入居の場合です。

- 借入額：3,600万円、毎月の返済額：98,302円
- 返済負担率：18.1%、審査金利（3.5%）での負担率：27.5%、判定：ゆとり
- 住宅ローン控除：1年目14万円、10年間で140万円（最大額）

### 印刷と共有

- **印刷**：入力欄を除いた「資金計画書」の部分だけが、A4縦で印刷されます。印刷画面で保存先にPDFを選ぶと、PDFにできます。
- **共有リンク**：入力した条件が、URLの「#」より後ろに入ります。リンクを受け取った人は、同じ条件の画面を開けます。リンクを渡した相手には、入力した数字が見えます。

## まだ計算に含めていないこと

- 固定資産税の負担調整措置、自治体独自の軽減、東京23区の都市計画税の独自軽減
- 修繕積立金・管理費・固定資産税の将来の変動（返済期間中は一定と仮定）
- 給与以外の所得がある場合の住宅ローン控除の所得要件（給与収入のみと仮定）
- 2023年末までに建築確認を受けた「その他住宅」の新築の住宅ローン控除の特例
- 低価格の物件（800万円以下）の仲介手数料の特例（該当する場合は注記を表示します）
- 所得金額調整控除など、給与所得控除以外の所得計算の調整
- 団体信用生命保険料、保証料（保証料型の場合は「その他」に入力してください）
- 引っ越し、家具・家電、リフォームの費用、駐車場代
- ボーナス払い、繰り上げ返済、金利の変動

## 法制度・税制の変更について

- 税率、軽減措置の適用期限、適用の要件は、税制改正で変わることがあります。
- 主な適用期限は、建物・抵当権の登録免許税の軽減と売買契約書の印紙税の軽減が2027年3月31日、土地の登録免許税の軽減が2029年3月31日、住宅ローン控除が2030年12月31日入居分までです。
- 期限を過ぎた税率は、画面に警告を表示します。更新は `rates.js` の該当箇所を書き換えて行います。
- 税率・控除額などの法令の数値は、2026年10月25日に国・自治体の公式情報で確認しています。ただし、不動産取得税の税額の端数処理（100円未満切捨て）は公式資料での確認ができていません（影響は100円未満です）。
- 次の点は、法令ではなくこのツールの計算上の仮定です：評価額の推計（価格の約6割）、給与収入のみとした所得要件の判定、住民税の課税総所得金額等を所得割の半分とする近似、諸費用分の借入を控除の対象外とする扱い、維持費を一定とする扱い。
- 実際の手続きや契約の前には、国税庁・法務局・都道府県・市区町村などの公式情報、または税理士・司法書士・金融機関などの専門家にご確認ください。
